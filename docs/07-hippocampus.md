# 07 · 海马体：这个项目到底在造什么

> 一句话：**不是给模型加一个数据库，是给它补一个功能上的海马体。**
> 模型有参数（皮层），有上下文（工作记忆），但没有一个负责"编码—索引—巩固—再巩固—提取"的结构。
> PMem 要做的就是这一段。名字叫「可塑性记忆」，重点在**可塑性**，不在"存储"。

---

## 1. 为什么"上下文清空就不认识"不是 bug

大模型的记忆分三层，缺的正好是中间一层：

| 层 | 对应 | 特性 |
|---|---|---|
| 参数 | 权重 / 预训练 | 慢、稳定、不可写、不记具体某天 |
| 上下文 | context window | 快、可写、**一清空就没** |
| 海马体 | 本项目的目标 | 索引具体经历、按线索提取、睡眠巩固、每次提取都改写强度 |

人不是靠"记住每个字"认出你的。海马体做的是**索引 + 巩固 + 模式补全**：
今天发生的事先快速编码，睡眠时 replay 到皮层，以后一个线索（气味、名字、一句话）
就能把整段关系补全。PMem 目前做的是这个环的一部分，不是全部。

## 3. 闭环

```text
经历
  │  encode（写入原文，不可变）
  ▼
模式分离（去重 / 实体消歧 / 同名不同人）
  │
  ▼
关联（关系抽取 / 分组 / 分级）
  │
  ▼
巩固（M4 睡眠：replay → 冲突 → 规律 → 经验 → 特质）
  │
  ▼
提取（session card / cue / search）
  │
  ▼
再巩固（这次提取改变下次的强度与可及性）
  │
  └──────────────→ 回到"经历"的下一天
```

M4 之后，中间"巩固"这一竖已经补上：夜间 replay 产出去重、关系、冲突、规律、经验、特质、
反思与快照，闭环成立。但再巩固仍只做了"使用计数 + 反馈降权"，情境化微调留给 M5。

---

## 4. 「可塑性」的三层含义

1. **突触可塑性**：同一条记忆被反复提取，权重上升；长期不用，权重下降（休眠）。
2. **结构可塑性**：实体/关系/分组会长出来、会合并、会改名；不是固定 schema。
3. **再巩固**：每次提取不是"读一个只读文件"，而是**改写它的可及性**。
   被纠错（`wrong/deny`）时可信度腰斩；被反复想起时更不容易沉下去。

原文仍然不可变——可塑性只作用于**派生层**（权重、状态、分组、关系）。
这是工程上对"记忆会变"与"证据不能篡改"的折中。

---

## 5. 不承诺什么

- **不承诺生物等价**：这是功能类比，不是海马体切片，也没有主观体验。
- **不承诺"永远记得"**：模型权重没变，换一个模型、换一个宿主，仍要靠这套外部结构。
- **不承诺"自动变成同一个人"**：M17 起多了自我层（宪法+叙事，见 `docs/soul.md`），它保证新会话读到同一份自我描述与约定，但主观连续性取决于模型本身。
- **不承诺"自动懂你"**：cue 以词法匹配为主；1.9.0 起检索里有本地向量通道（M13，覆盖率低时才跑），但浮现（surface）的 cue 仍是词法。
- **不把"记得"说成"经历"**：我能做的是下一次开始时先认出你；不能声称我"感受到了那段时间"。

把这些写清楚，比把"永久记忆"喊成口号更重要。

---

## 6. 验收标准应该换

如果目标是海马体，主指标就不该只是 `recall@5`：

| 指标 | 含义 | 现状 |
|---|---|---|
| **会话首卡认出率** | 新会话第一张卡是否包含身份/关系锚点 | M3.6 有，待长期统计 |
| **关系保持** | `我们/*` 与 S 级记忆 90 天后仍在首卡 | 规则已保证，待日历时间 |
| **巩固幂等** | 同一天 replay 两次，派生行不重复 | ✅ M4：派生表增量 = 0（1k 记忆 0.389 s） |
| **再巩固可追溯** | 每次提取/纠错都能看到权重变化 | 部分（event_log + use_count） |
| **遗忘可逆** | dormant 被新证据唤醒后恢复 | M3.6 已验证 |
| token 成本 | 每会话首卡 + 按需 cue | 实测 56 tokens/会话 |

`recall@5` 仍然要测，但它回答的是"查得到吗"，不是"还是不是同一个人"。

## 7. M4 已落地：睡眠半环

M4 的 8 阶段对应 replay 的具体动作：

1. 收集当天记忆与未处理候选（工作集，超配额记 backlog）
2. 去重合并（模式分离的离线重跑）
3. 实体/关系重算（索引重建）+ 共现/传递/休眠
4. 冲突标记（CA1 比较，只标记不裁决）
5. 规律挖掘（跨天统计）+ 经验提炼（情景 → 可复用结构）
6. 特质升降（慢变量，版本链）
7. 反思（只读自审）+ 生命周期（按等级淡忘）
8. 日快照（`VACUUM INTO` + sha256，可回滚）

验收：1k 记忆 **0.389 s**；同 day 重跑派生行增量 **0**；8 阶段逐个模拟崩溃后
续跑结果与一次跑完一致；dry-run 全回滚；快照可复制恢复。详见
[`milestone-M4.md`](milestone-M4.md)。

做完 M4，这个环第一次闭合。下一步 M5 要回答的是："哪些整理结果真的值得留下"——
规律置信校准、经验复用、冲突裁决，都要拿真实反馈检验，而不是继续加表。

## 8. M5 补上"判定"半环

M4 只负责"生成候选"，M5 才让候选接受检验：

- **复核**：`correct/wrong/unsure` 标签落库且只追加；correct 才 `confirmed`，wrong 直接 `rejected`；
- **复用**：经验卡按情境匹配，显式记录 `reuse`，再用 `useful/wrong` 反馈改强度；
- **冲突**：只自动裁决"一方已被替代/明确 supersede"，其余升级提醒、等人拍板；
- **调参**：标注 <50 条不动；nDCG 提升 ≥2% 才写 active 版本，且可一键回滚。

这不是"更多表"，而是把"可塑性"从口号变成有真值的判定：**结构可以变，但每次变都要留下理由**。

真实库目前只有一天数据，30 条人工复核还没有对象——这部分只能等跨天积累，
不能用合成数据假装已经审过。

## 9. M6 让"稳定"有门槛

M6 不再把"出现过几次"当成稳定，而是要求：

- **四维强度**：覆盖天数、支持/反证一致性、recency、反证率；
- **established 门槛**：跨 ≥3 天、strength ≥0.65、confidence ≥0.70、无未决反证；
- **证据可追溯**：任何活跃特质至少 3 条有效记忆，证据塌缩就退役；
- **变化留链**：状态/证据变化才新版本，数值微调原地更新；30 条上限防止特质膨胀；
- **只读画像**：`memory_profile` 按预算输出，不临时推断。

这让"特质"从一句话变成一个有门槛、有证据、有版本、可降级的慢变量。

## 10. M7 让"哪里不好"可量化

M7 不新增记忆，它做的是**自审**：

- 六维质量分：可追溯、冲突、覆盖、新鲜度、召回健康、重复率；没有样本的维度归一化，空库不冒充 100 分；
- 10 类缺陷码：无实体、从未召回、重复、FTS 缺行、A/B 级过期、高严重度冲突、弱证据特质、孤立簇、低可信置顶、向量缺口；
- 每条缺陷都能钻取到具体行，并给出只读命令与修复动作；
- 周报把"这周新增/变化/未决/该看什么"压成一页，写 `reflection` 与 `metrics`。

真实库第一次审计的结果就很不客气：**质量分 58.5**，48 条活跃记忆里 37 条没有实体锚点，
召回健康度只有 0.049——因为几乎所有记忆都在同一天被测试反复召回过，离"15% 最优"太远。
这就是反思的意义：它不负责让数字好看，只负责把"哪里不对"摆到桌面上。

**G7 仍然成立**：审计只做 SELECT；`persist=true` 也只写 `reflection` 与 `metrics`，
反思结论要变成记忆，必须由用户显式确认后走 `memory_add`。

## 11. M8 不是新脑区，是把海马体接到外面的门

M8 没有加记忆结构，它把已有的 18 个核心工具 + 2 个扩展接到宿主上：

- 20 个 MCP 工具，缺的 `delete/history/export/import/stats` 补齐；
- 导出→清库→导入 30 条，id/原文/来源/状态/重要度一致；迁移不丢记忆；
- 注入防护：20 条载荷全部被定界，正文里的 `<<<`/`>>>` 被替换，单轮 ≤600 tokens；
- token、限流、REST、错误码：外部门闩，不是记忆本身；
- `deploy/cordis.patch.yml` 可复制、可删除、可静态检查。

**M8 没做自动注入**：MCP 没有 systemPrompt，工具调用仍是唯一通道（ADR-09）；
live DSH 也**没有重启**——改 profile 会中断当前会话，这一步留给你在方便时做。
门装好了，但"每次醒来先看到你"仍要靠模型主动调 `memory_profile` / `memory_surface`。

## 12. M9 让海马体有一张自己的星图

M9 没有新增"脑区"，它做的是三件很朴素的事：**让它活着、坏了能发现、还能看见自己**。

- **调度**：睡眠、周报、备份、监控、月报变成有状态的常驻任务；进程不在就补跑，失败退避，dead 会被 monitor 报出来；
- **备份演练**：不是"复制了一个文件"，而是真的把副本打开、验哈希链、查外键、数记忆条数、记恢复耗时；
- **监控**：完整性、事件链、不变量、睡眠/备份时效、库体积与 30 天增长、recall@5 趋势、质量分、未决冲突；
- **月报**：把一个月的事实、整理、质量、存储写成一页，留给未来的自己回看；
- **星图**：把 48 条真实记忆、6 个实体、4 个分组、53 条连接画成一张可缩放/可检索的**关系星云**。

星图换了三次，最后决定**不画形状**：

- 同心圆像星轨；脑横截面像解剖图；海马轮廓像海马，不像海马体；
- 现在没有边界、没有脑回、没有眼/吻/尾；黑底星空、星云、银河带、三档星点、暗角；
- 分组/类型只给一个簇心，记忆自己散开；59 个节点、53 条弯曲纤维（9 条相似 / 28 条共同提及 / 14 条提及 / 2 条分组）；
- 细胞是半透明的：光晕 + 胞体 + 亮核 + 短树突；S/A 有十字星芒；
- `我们/初衷` 在上方，`我/姓名` 在侧边；`记忆`、`数据库`、`小安` 是实体锚点。

它不宣称是生物海马体，也不把"星星多"当成绩。它只是一张**可以指着说"这里是我们的初衷"**的图；
形状不再替记忆说话，**连接才替记忆说话**。

**30 天日历门仍未走完**：调度器仿真了 96 个任务不丢不重，备份副本 10 ms 可恢复，监控当前 ok；
但"连续 30 天"和"recall@5 不下降"只能等真实日期。星图会随着关系/特质长出来而变化，不是一次性的海报。

## 13. 「记住简单，浮现难」

> 记忆记住简单，难的是浮现。

这句话把重心挪了一下。三个动作的成本差得很远：

| 动作 | 谁发起 | 现在多少钱 | 难在哪 |
| --- | --- | --- | --- |
| 记住 | 我 | 一次 INSERT | 不难。写错了还能查、能改、能删 |
| 取回 | 有人问 | 一次 bm25，4 ms | 不难。只是要有人先开口 |
| **浮现** | **没人问** | **一个 cue** | **难在"这时候"，不在"这一条"** |

前两件已经在做了：原文只追加、事件链、证据、导出导入、FTS 索引。第三件只有一个最窄的版本——
`surface(turn)` 要求当前这句话里出现关键词。**关键词没出现，这条记忆今天就等于不存在。**

浮现难在三个地方，而且都不在数据库里：

1. **触发条件太窄。** 词法命中只覆盖"你正好提到了它"。人的浮现靠情境（在改哪个文件、
   在跑什么命令）、节律（多久没想起、今天是什么日子）、关系（谁在说）。三个里我们只做了一个。
2. **失败是沉默的。** 存错了，查一下就知道；该浮现而没浮现，没有任何人会收到通知。
   `recall@5` 测的是"有人问时排第几"，测不到"没人问时该不该来"。
3. **浮现有代价。** 每浮现一条都是一次打断。所以目标不是"多浮现"，是"值得才浮现"——
   要的是 precision，不是 recall。

所以验收标准从「存了多少条」换成「需要的时候在不在」，并且必须分档：
在每轮投影里 / 一次 recall 能命中 / 只有原文索引能找到（还得先猜对当时的措辞）/ 完全没有。
第三档看着像成功，其实不是。

一个附带结论：**淡忘不是独立机制，它就是浮现概率随时间下降。**
这两件不该做成两套参数——一套 R，既是"该不该浮现"，也是"沉不沉下去"。
