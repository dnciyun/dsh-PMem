# PMem 控制台 · 需求澄清记录（50 轮问答）

> 这是「用户 × Lead」的 50 轮需求问答记录与结论，不是产品功能。
> 产品里**没有**问答/聊天：控制台只是可视化管理台。
> 契约里的后端实现见 `docs/console-design.md`（§5.7/§5.8 已作废，后端已按新范围交付）。

状态：第 1–3 轮已完成（2026-11-05），第 4 轮待问。

---

## 第 1 轮：定位与「替代卡片」

| 问题 | 回答 |
|---|---|
| 「卡片」指什么 | **设置弹窗里的「可塑性记忆」卡片窗口**（七个标签全塞在弹窗里） |
| 最想解决 | ①搜得到、看得清一条记忆的全部来路 ②能纠错（改标签/反馈/撤回/删除）③一眼看健康度 ④排查插件故障 ⑤夜间/大睡进度 ⑥星图浏览 ⑦能演示、截图好看；补充：**可修改的参数**也要 |
| 谁用 | **只有自己用** |
| 入口 | 侧边栏顶部一行：图标 +「记忆控制台」 |
| 屏幕 | **桌面大屏优先** |
| 视觉 | **跟 DSH 一致**，克制、信息密度高（深浅色自动适配） |

**结论**：不是新做一套视觉，而是把设置弹窗里的功能全部搬到整页，加密度、加可操作性。

## 第 2 轮：结构与管理动作

| 问题 | 回答 |
|---|---|
| 页面结构 | **左侧二级导航 + 右侧内容区** |
| 记忆页 | **左侧列表 + 右侧详情**（宽屏两栏） |
| 详情要哪些块 | 完整正文+日期/kind/grade/分组；证据（原话+行号）；变更历史时间线；冲突与相关记忆；**实体/关联网**；使用统计；**一键复制 JSON/命令行** |
| 可改参数 | 运行时开关；预算与频率（醒来卡预算/浮现冷却/超时/handoff 间隔）；检索默认值（k/mode）；夜间睡眠参数（批大小/模板/DSH）；**模型/嵌入通道开关（向量通道重建）**；补充「**可以开放更多权限**」 |
| 危险操作 | **删除二次确认+默认软删**；**支持多选批量操作**（反馈/撤回/删除） |
| 睡眠页 | run 列表+八阶段；**每阶段耗时/条数小条形图**；现在入睡+大睡一场；**大睡进度实时（当前天/阶段）**；**最近 N 天质量趋势** |

**结论**：控制台是「能动手的管理台」，不是只读看板。

## 第 3 轮：旧页面、搜索、实体、排查、权限

| 问题 | 回答 |
|---|---|
| 旧设置页 | **旧标签全删，只留一行「打开控制台」按钮** |
| 总览首屏 | 指标条（总量/今日新增/待办/冲突/使用次数）；最近 10 条；睡眠状态；今日 token/上下文用量（拿得到的话）；请求健康（401/500/404 自检）。（**没选**醒来卡预览/星图预览——总览要清爽） |
| 搜索 | 语义（向量）；词法；最近；日期范围/分组/等级/来源过滤；实体/人物过滤；**按原话反查（trace）** |
| 实体/关系 | **单独一个「实体/关系」分区**（1/2 跳查询、合并实体） |
| 排查面板 | 最近 API 请求日志；醒来卡缓存内容+刷新；MCP 探活+工具数；**路径体检**；数据库 doctor/体积/完整性；配置差异（profile vs runtime.json） |
| 开放权限 | 改任意记忆元数据（kind/grade/分组/敏感级）；**批量撤回/删除（二次确认）**；重跑向量编码/重建索引；数据库备份/恢复（危险，单独高级区） |

**结论**：
- 分区从 5 个变为：**总览 / 记忆 / 实体 / 睡眠 / 设置（设置里含「排查」和「危险区」）**。
- 设置页不再只是开关，要有「排查面板 + 危险区（备份/恢复/重建索引）」。

## 当前定稿的信息架构（v2）

### 入口
- 侧边栏顶部一行：图标 +「记忆控制台」，`order` 紧挨插件页。
- 设置 → 可塑性记忆：**只留一行**「控制台已独立：打开控制台」，点击 `ctx.layout.selectPanel('pmem-console')`。
- 不改任何既有 slot 名称；`main` keyed slot key = `pmem-console`。

### 总览
- 指标条：记忆总量 / 今日新增 / 待办 / 未决冲突 / 使用次数（来自 `/console/bootstrap.counts`）。
- 今日 token/上下文用量：能拿到 `tokenMeter` 就给，拿不到显示「—」并标注。
- 请求健康：最近请求里 4xx/5xx 计数 + 最近 5 条异常（来自 `/debug`）。
- 睡眠状态：上次睡眠时间 / 状态 / 质量分；按钮「现在入睡」「看睡眠」。
- 最近 10 条记忆：点开进「记忆」分区并选中。
- 快捷动作：打开星图、体检（doctor）、刷新醒来卡。

### 记忆
- 顶部工具栏：搜索框；模式（auto/keyword/vector/recent）；过滤（kind/grade/status/group/日期范围/实体名）；「按原话查」开关（trace）；结果计数。
- 左列：结果列表（高亮、时间、kind/grade/来源标签、score 条、置顶标记）；支持**多选**（复选框）。
- 批量工具栏出现时：打反馈 / 撤回 / 删除（全部二次确认，默认软删）。
- 右列详情：
  - 完整正文（可复制）
  - 元数据编辑：kind / grade / 分组 / 敏感级 / 重要度（保存调 `/memory/update`）
  - 证据（原话+行号+会话）、变更历史时间线、冲突、相关记忆、实体/关系、使用统计
  - 动作：有用/无关/错了/确认/置顶/撤回/删除
  - 「复制 JSON」「复制 CLI 命令」（`pmem get <id>`）
- 空态/错误态可读；搜索无结果给「换词/看最近」。

### 实体
- 左列：实体搜索/列表（name、type、mentions、grade、groups）。
- 右列：实体详情（别名、提及它的记忆列表、1 跳关系、2 跳查询输入、合并入口）。
- 合并：选两个实体 → 预览 → 确认（调 `pmem net merge`，需二次确认）。
- 空态说明「还没有实体，跑一次 `pmem net extract`」。

### 睡眠
- 顶部：现在入睡 / 大睡一场（模板/DSH、日期范围、演练）/ 刷新。
- run 卡片：八阶段展开；每阶段右侧小条形图（耗时/条数，取 stage.ms / 阶段 stats 数值）；失败红色、跳过灰色。
- 进行中 run：进度条（当前天/阶段，轮询 `/sleep`）。
- 趋势：最近 14 次质量分折线（SVG 手写，不引图表库）。

### 设置
- 运行时：surface / starmap / starmapLive / budget / surfaceCooldownMs / surfaceTimeoutMs / handoffTurns / handoffMinMs / contextAuto（`/config`，保存即生效）。
- 检索默认：默认 k、默认 mode（存 localStorage，仅前端默认值）。
- 模型/嵌入：向量通道状态（`/stats` 或 `/doctor`），「重建索引」（调 `pmem vector rebuild`，危险区确认）。
- 夜间：大睡默认参数（模板/DSH、批大小）。
- 排查面板：请求日志（最近 20）、醒来卡缓存（内容+刷新）、MCP 探活+工具数、路径体检、doctor/体积/完整性、配置差异（profile vs runtime 显式值）。
- 危险区（折叠，红色描边）：数据库备份（`pmem backup`）、恢复（上传/选择文件，二次确认输入 `RESTORE`）、硬删除。
- 关于：版本、仓库路径、数据规模、MCP 24 工具、命令行速查。

### 交互与视觉
- 桌面大屏优先；窄屏 <900px 两栏堆叠；左右导航可收起（纯图标）。
- 视觉跟 DSH 一致：`--dsw-alias-*` 变量、圆角 10–14px、13px 正文、高信息密度。
- 可访问性：左侧导航 `role=tablist`、方向键；危险操作二次确认；toast 提示。
- 刷新：切分区时按需拉取；总览每 30s 轮询；睡眠/请求日志手动刷新 + 进行中 5s 轮询。
- 空态、加载态、错误态（含错误码与重试）全覆盖。

## 第 4–9 轮补充结论（2026-11-05 收尾）

- **一级分区**：总览 / 记忆 / 实体 / 睡眠 / 设置（排查在设置内）。
- **总览取消「待办」指标**，换成「今日召回」（`counts.today_recalls`，拿不到显示 —，fallback 近 7 天新增）。
- **批量操作**：每条前复选框 + 底部浮动工具条（已选 N 条）；批量反馈/撤回/删除 + **批量改元数据**（kind/grade/group/sensitivity/importance/status，逐条回写、二次确认）。
- **备份**：跟 CLI 一致（数据库同目录/backups），一键生成 + 列出 + 下载；恢复只给命令行指引（输入 RESTORE 的 UI 恢复留待后端支持）。
- **刷新**：按需 + 总览 30s + 睡眠进行中 5s；不做全局 SSE。
- **名字**：「记忆控制台」；标题「PMem · 可塑性记忆」。
- **图标**：海马轮廓；**顶栏**：标题+版本 chip、状态灯（DB 可写 / 模型通道 / MCP）、最后刷新时间+刷新。
- **排序**：分段按钮（相关度/时间/重要度/使用次数）；默认有搜索词=相关度、无词=时间倒序；列表「加载更多」（每页 20，可选 50）。
- **分组过滤**：左侧可折叠树、含子组、多选。
- **元数据编辑**：kind（下拉）、grade（S/A/B/C/D）、分组（树选/新路径）、敏感级（secret 二次确认）、重要度（滑块+数字）、状态（active/contested/dormant/archived）、置顶。
- **撤回 vs 删除**：两个按钮分开；撤回橙色（不删原文）、删除红色（默认软删 + 二次确认）。
- **实体页**：列表 + 详情（别名/提及/1 跳）+ 2 跳查询 + 合并（先服务端 dry_run 预览再确认）+ 跳星图；不做新增/休眠关系，不做 SVG 关系图（可视化交给星图）。
- **危险确认**：备份一键；重建索引/恢复需输入 RESTORE；删除/合并二次确认。
- **错误展示**：人话一句 + 可折叠技术细节（状态码/命令/stderr）。
- **请求健康**：总览一行（API 正常 · 最近100条 4xx/5xx N · 醒来卡 X 分钟前），点击展开。
- **不加**：键盘快捷键、主题/密度切换、演示模式。
- **要**：空库引导（建库/写第一条/导入/看文档）；页面截图按钮；记忆导出 JSONL/Markdown（P2）。
- **数据规模**：几百到几千条，不做虚拟滚动。
- **访问**：只在 DSH 桌面/本机 Web，不做远程/手机特化（窄屏堆叠保留）。
- **下一轮重点**：记忆页打磨（搜索/过滤/批量/详情）。


1. 侧边栏入口 + 整页骨架 + 总览
2. 记忆搜索/详情/反馈/更新/删除（含二次确认）
3. 睡眠页（列表+阶段+现在入睡）
4. 设置页（运行时开关+排查）
5. 实体页 + 批量操作 + 向量重建 + 备份恢复（P1，不阻塞首版）
6. 趋势图、请求健康、token 用量（P2）

验收：真实 DSH 隔离 profile + 截图（见 task-4），浏览器 console 无错。

## 第 10 轮补充（插件 0.9.0）：醒来卡要有页面

- 现象：醒来卡（每轮注入 system prompt 的那张「我是谁 / 为什么做这个 / 现在在做什么 / 下次从哪里接」）
  在界面上**看不见**——总览只有「醒来卡 260 字」一行计数，设置页排查面板里得点「刷新醒来卡缓存」才出一段 pre。
- 定稿：控制台新增**一级分区「醒来卡」**（排在总览后面），左侧导航从 5 个变 6 个。
- 页面内容：全文（`/console/bootstrap.wake.text` 或 `/wake?budget=N` 重取）、字数/约 token/取的时间、
  「重取」（不落库）、「复制全文」、以及「每轮预算」输入 + 「存为每轮预算」（写 `/config` → runtime.json 的 budget，下一轮生效）。
- 数据同源：注入和这个页面都走 `pmem wake --budget`，看到的就是实际注入的那份卡，不另存副本。
- 总览「快捷动作」加「看醒来卡」直接跳过去；仍然**不做**总览内嵌预览（总览要清爽）。

## 第 11 轮补充（插件 0.9.1）：用法教程放进醒来卡页，但默认折叠

- 需求：醒来卡页里顺便教怎么用 PMem（用什么存、怎么看、怎么改），但**不展示出来**——不能变成占用版面的说明文档。
- 落地：页内一个 `<details class="pconsole-help">`（默认收起），标题「PMem 怎么用？（点开 · 记 / 找 / 改 / 夜里的整理）」。
- 内容五块：① 想让它记住（说「记住：…」/ `/pmem remember` / `pmem add`）；② 想找回来（直接问 / `/pmem recall` / 记忆页搜索）；③ 想改·纠错·忘掉（记忆页详情、supersede 不删原文、撤回留墓碑）；④ 夜里的整理（模板 vs 鲸眠，大睡一场先小范围）；⑤ 速查表 8 行（记忆 / 搜索 / 醒来卡 / 更新 / 撤回 / 夜睡 / 自检 / 配置）。
- 速查表底下一个「复制这份速查」（纯文本，方便贴给别人）。
- 原则：教程只做**入口**，正文仍以仓库 `README.md` / `docs/` 为准，不在前端复制第二份会过期的文档。
